# Bakery On Demand!

tiny cozy web app that helps you figure out what to bake with whatever you already have / want to get rid of.

type in some ingredients, hit the add button, and it will find you a random baking recipe to learn.

kind of like opening your pantry and hoping something good happens.

### What it does

- lets you add ingredients by name one at a time
- builds a little pantry list
- pulls recipes based on what you have
- gives you a random baking idea

### Why?

i wanted something i could actually use when im standing in my kitchen like "...okay i have a random pack of jello mix ... flour... and lemon frosting. something has to happen."

also an excuse to make something that feels warm and a little personal instead of super corporate minimal design.

### Features

- ingredient list builder with add and remove buttons
- random recipe generator
- soft bakery style UI
- optional background music (vinyl included)

### Built with

- HTML / CSS / JavaScript
- Spoonacular API

### Note

this is simply a personal project, so its a little experimental and will probably evolve over time as i learn.

if it suggests something that makes no sense... thats part of its charm i swear.

made with lots of sugar and love. <3
